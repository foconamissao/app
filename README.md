# Foco na Missão — Missão PE

V1.0 (fundação) da nova plataforma, criada do zero.

## Configuração
1. Crie um projeto novo no Supabase.
2. Abra o SQL Editor e execute `supabase/schema.sql`.
3. Em `js/supabase.js`, informe `SUPABASE_URL` e `SUPABASE_ANON_KEY`.
4. Crie o primeiro usuário pelo Supabase Auth.
5. No SQL Editor, altere o perfil desse usuário para `admin` se necessário.
6. Publique esta pasta em um repositório novo no GitHub Pages.

## Importante
- Não há simulados personalizados. Somente simulados oficiais criados pelo administrador.
- O brasão oficial da Missão PE deve ser colocado em `assets/logo/missao-pe.png`.
- RLS está habilitado no banco.
